Install

One line and you're done.

Homebrew is the easiest way in: one command puts Hoardmap in your Applications folder, ready to open. No account, nothing running in the background.

Recommended

Homebrew

Paste this into Terminal.

$ brew install --cask abhishekkundu25/tap/hoardmap
  • Opens straight away, first time
  • Update with brew upgrade
  • Don't have Homebrew? Get it at brew.sh

Download

Open Hoardmap.dmg and drag the icon into your Applications folder, like any Mac app.

  1. Get Hoardmap.dmg and open it.
  2. Drag Hoardmap onto Applications.
  3. First time only: in System Settings → Privacy & Security, press Open Anyway.

Features

Everything big, in plain sight.

Inspired by WinDirStat, rebuilt in Rust for the Mac. Three views that follow each other, so the biggest thing is never more than a click away.

Seriously fast

Scans a whole home folder, nearly a million files, in about three seconds, on every core.

Treemap and icicle

Every file is a block sized by bytes, coloured by type. Or flip to the icicle to see where it sits in the hierarchy.

Linked views

Click a block and the folder list jumps to it. Pick a file type and every file of that type lights up.

Real disk usage

Shows what files actually take on disk, so a 64 GB Docker image that only uses 5 GB doesn't fool you.

Straight to Finder

Double-click anything and Finder opens with it selected. Clear it out there, then press Rescan.

Private by design

Works fully offline. Nothing leaves your Mac, and Full Disk Access is optional.

Safe by design

It only looks.

Hoardmap has no delete button, anywhere. It reads sizes and shows you the way. What you remove, you remove yourself, in Finder, after you've seen it.

  • Never deletes, moves or renames
  • No network, no tracking, no account
  • Opens Finder at what you pick
  • Open source, MIT licensed

For the terminal

Prefer a command?

The hoardmap command scans any folder and opens the same map in your browser. It quits on its own when you close the tab.

Install it with Homebrew, download the command, or build it from source.

$ brew install abhishekkundu25/tap/hoardmap

$ hoardmap ~/Developer
Listening on http://127.0.0.1:52817/
