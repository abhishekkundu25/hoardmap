# Homebrew tap for Hoardmap

[Hoardmap](https://github.com/abhishekkundu25/hoardmap) shows where your Mac's disk space
went, as a list, a treemap and an icicle chart. It only looks: it never deletes, moves or
renames anything.

```sh
brew install --cask abhishekkundu25/tap/hoardmap
```

This installs the app and the `hoardmap` command, which opens the app on a folder:
`hoardmap ~/Developer`. Update with `brew upgrade`.
